# Тестовое задание — Tower Defense, затрачено 16ч

## Описание проекта
Небольшая демо-игра в жанре **Tower Defense**, выполненная на Unity3D.  
Игрок располагает валютой и может строить башни двух типов, чтобы уничтожать врагов, двигающихся по заданному маршруту.

## Основной функционал

### Игровое поле
- Сетка ячеек воплнена как отдельные кастомные ячейки, в которые могут устанавливаться башни.
- Дорожка, по которой враги идут от точки появления до конечной точки с использованием Navmesh + navmesh plus 2d

### Башни
Каждая башня имеет параметры:
- Урон  
- Радиус атаки  
- Скорость атаки  
- Стоимость постройки  

Типы башен:
- **Лучник** — стреляет одиночным снарядом по выбранной цели.  
- **Подрывник** — выпускает снаряд, наносящий урон по области.

Башни атакуют только после того, как плавно повернутся к цели.

### Враги
- Появляются в начальной точке и движутся к финалу.
- Имеют запас здоровья, скорость, базовые анимации.
- Уничтожаются при достижении конечной точки или при смерти.
- За убийство игрок получает валюту, кол-во от типа врага.

### Валюта и UI
- На интерфейсе отображается текущее количество валюты.
- Есть две кнопки: постройка башни лучника и подрывника.
- Если валюты недостаточно, кнопка становится неактивной.
- При строительстве башня размещается в случайной доступной ячейке.

## Визуализация
Графика собрана из примитивных объектов Unity, без использования сторонних ассетов.

## Запуск
1. Открыть проект в Unity **(версия 6.000.0.49f1 или выше/миноры)**.  
2. Запустить сцену `SampleScene`.  

## Структура проекта
- `Scripts/` — основная логика игры  
- `Content/` — башни, враги, снаряды, графика  
- `Scenes/` — игровые сцены
